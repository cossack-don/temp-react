# flex-утилиты

Набор из 215 CSS-классов для флекс-раскладки. Именование как в Tailwind,
но это обычный статический CSS: ни сборщика утилит, ни рантайма, ни сканирования
исходников. Файл `src/app/styles/utils/flex.css` целиком генерируется скриптом.

> **Про префикс в примерах.** Ниже классы записаны без префикса — `flex`, `m-4`.
> Сейчас файлы сгенерированы с `--prefix cost-`, поэтому в разметке они
> называются `cost-flex`, `cost-m-4`, а отрицательные — `-cost-mt-4`.
> Проверить текущий префикс можно в шапке самого CSS-файла, строка
> «Сгенерировано».

## Генерация

```bash
npm run styles:flex                            # .flex      .items-center   .gap-4
npm run styles:flex -- --prefix con-           # .con-flex  .con-items-center
npm run styles:flex -- --step 2                # .gap-4 = 8px
npm run styles:flex -- --prefix con- --step 2
```

Скрипт: `scripts/css/generate-flex.mjs`, общая часть — в `scripts/css/_shared.mjs`.
Чистый Node, без зависимостей.
Результат: `src/app/styles/utils/flex.css` (перезаписывается целиком).

> **Файл руками не правят.** Любая правка исчезнет при следующей генерации.
> Нужен новый класс или другое значение — меняйте генератор.

### Префикс

Префикс приклеивается к имени класса. Отрицательные классы получают его
**после** минуса, как в Tailwind:

| без префикса    | `--prefix con-`     |
| --------------- | ------------------- |
| `.flex`         | `.con-flex`         |
| `.items-center` | `.con-items-center` |
| `.gap-2\.5`     | `.con-gap-2\.5`     |
| `.-order-2`     | `.-con-order-2`     |

Зачем он нужен: в режиме микрофронтенда (`npm run dev:mf`) стили хоста и
remote'а оказываются на одной странице. Голый `.flex` там почти наверняка
с чем-нибудь столкнётся — выиграет тот CSS, что загрузился последним.
Префикс это снимает.

### Базовый шаг

Шкала `gap-*` и `basis-*` считается в пикселях: **число в классе × шаг**.
Шаг задаётся флагом `--step`, по умолчанию 4px:

```bash
npm run styles:flex -- --step 2     # gap-4 станет 8px вместо 16px
```

Шаг у flex и margin задаётся независимо, но держать их разными — плохая идея:
`gap-4` и `m-4` перестанут означать одно и то же. Меняете шаг — прогоняйте оба
генератора с одинаковым `--step`.

| класс  | px  |     | класс | px  |     | класс         | px        |
| ------ | --- | --- | ----- | --- | --- | ------------- | --------- |
| `-0`   | 0   |     | `-4`  | 16  |     | `-16`         | 64        |
| `-px`  | 1   |     | `-5`  | 20  |     | `-20`         | 80        |
| `-0.5` | 2   |     | `-6`  | 24  |     | `-24`         | 96        |
| `-1`   | 4   |     | `-7`  | 28  |     | `-28`         | 112       |
| `-1.5` | 6   |     | `-8`  | 32  |     | `-32`         | 128       |
| `-2`   | 8   |     | `-9`  | 36  |     | `-40`         | 160       |
| `-2.5` | 10  |     | `-10` | 40  |     | `-48`         | 192       |
| `-3`   | 12  |     | `-11` | 44  |     | `-56`         | 224       |
| `-3.5` | 14  |     | `-12` | 48  |     | `-64`         | 256       |
|        |     |     | `-14` | 56  |     | `-80` / `-96` | 320 / 384 |

`-px` — ровно 1 пиксель, для подгонки границ. `-0` — ноль без единиц.

## Справочник классов

### Контейнер

| класс               | CSS                                  |
| ------------------- | ------------------------------------ |
| `flex`              | `display: flex`                      |
| `inline-flex`       | `display: inline-flex`               |
| `flex-row`          | `flex-direction: row` (по умолчанию) |
| `flex-row-reverse`  | `flex-direction: row-reverse`        |
| `flex-col`          | `flex-direction: column`             |
| `flex-col-reverse`  | `flex-direction: column-reverse`     |
| `flex-wrap`         | `flex-wrap: wrap`                    |
| `flex-nowrap`       | `flex-wrap: nowrap` (по умолчанию)   |
| `flex-wrap-reverse` | `flex-wrap: wrap-reverse`            |

### Поведение элемента

| класс                                                       | CSS                    | смысл                                                 |
| ----------------------------------------------------------- | ---------------------- | ----------------------------------------------------- |
| `flex-1` … `flex-12`                                        | `flex: N`              | доля свободного места; `flex-2` вдвое больше `flex-1` |
| `flex-auto`                                                 | `flex: auto`           | растёт и сжимается, отталкиваясь от своей ширины      |
| `flex-initial`                                              | `flex: 0 auto`         | сжимается, но не растёт                               |
| `flex-none`                                                 | `flex: none`           | фиксированный, не растёт и не сжимается               |
| `grow` / `grow-0`                                           | `flex-grow: 1 / 0`     |                                                       |
| `shrink` / `shrink-0`                                       | `flex-shrink: 1 / 0`   | `shrink-0` не даёт иконке сплющиться                  |
| `basis-<шкала>`                                             | `flex-basis: Npx`      | `basis-24` → 96px                                     |
| `basis-auto`                                                | `flex-basis: auto`     | по содержимому                                        |
| `basis-full`                                                | `flex-basis: 100%`     |                                                       |
| `basis-1/2` `basis-1/3` `basis-2/3` `basis-1/4` `basis-3/4` | доли                   | 50% / 33.33% / 66.67% / 25% / 75%                     |
| `order-1` … `order-12`                                      | `order: N`             |                                                       |
| `-order-1` … `-order-12`                                    | `order: -N`            |                                                       |
| `order-first` / `order-last` / `order-none`                 | `-9999` / `9999` / `0` |                                                       |

**`flex-1` против `flex-auto`** — разница в базисе. `flex-1` это `1 1 0%`:
все элементы получат одинаковую ширину независимо от содержимого.
`flex-auto` это `1 1 auto`: свободное место делится **поверх** естественной
ширины, поэтому блок с длинным текстом останется шире соседей.

### Выравнивание

По главной оси — `justify-*`:

| класс                 | CSS             |
| --------------------- | --------------- |
| `justify-start`       | `flex-start`    |
| `justify-end`         | `flex-end`      |
| `justify-center`      | `center`        |
| `justify-between`     | `space-between` |
| `justify-around`      | `space-around`  |
| `justify-evenly`      | `space-evenly`  |
| `justify-stretch`     | `stretch`       |
| `justify-baseline`    | `baseline`      |
| `justify-normal`      | `normal`        |
| `justify-end-safe`    | `safe flex-end` |
| `justify-center-safe` | `safe center`   |

По поперечной оси — `items-*`:

| класс                 | CSS                      |
| --------------------- | ------------------------ |
| `items-start`         | `flex-start`             |
| `items-end`           | `flex-end`               |
| `items-center`        | `center`                 |
| `items-baseline`      | `baseline`               |
| `items-baseline-last` | `last baseline`          |
| `items-stretch`       | `stretch` (по умолчанию) |
| `items-end-safe`      | `safe flex-end`          |
| `items-center-safe`   | `safe center`            |

**Про `-safe`.** Обычный `items-center` при нехватке места центрирует так, что
контент вылезает за оба края, и до верхней части не доскроллить — прокрутка
в ту сторону недоступна. `items-center-safe` в этом случае откатывается
к началу оси, и контент остаётся достижимым.

Для одного элемента — `self-*`: `self-auto`, `self-start`, `self-end`,
`self-center`, `self-stretch`, `self-baseline`.

Распределение рядов (нужен `flex-wrap`) — `content-*`: `content-normal`,
`content-start`, `content-end`, `content-center`, `content-between`,
`content-around`, `content-evenly`, `content-stretch`.

### gap

| класс           | CSS                                      |
| --------------- | ---------------------------------------- |
| `gap-<шкала>`   | `gap` — и по горизонтали, и по вертикали |
| `gap-x-<шкала>` | `column-gap`                             |
| `gap-y-<шкала>` | `row-gap`                                |

`gap` работает и во флексе, и в гриде, и корректно ведёт себя при переносе
строк. Старый приём с `margin` у всех детей кроме первого здесь не нужен.

## Типовые раскладки

### Шапка: логотип слева, навигация справа

```html
<header class="flex items-center justify-between gap-4">
  <a href="/">Логотип</a>
  <nav class="flex items-center gap-4">
    <a href="/about">О нас</a>
    <a href="/contacts">Контакты</a>
  </nav>
</header>
```

Когда элементов больше двух и прижать к краю нужно только последний,
`justify-between` начинает расползаться. Надёжнее `margin-inline-start: auto`
на последнем блоке — он съедает всё свободное место слева.

### Строка списка: иконка, растягивающийся текст, кнопка

```html
<li class="flex items-center gap-3">
  <img class="shrink-0" src="…" width="32" height="32" />
  <div class="flex-1">
    <p>Очень длинное имя пользователя</p>
    <p>user@example.com</p>
  </div>
  <button class="shrink-0">Открыть</button>
</li>
```

`shrink-0` на иконке и кнопке — чтобы не сплющились, когда текста много.

### Центрирование

```html
<div class="flex items-center justify-center">
  <div>Ровно по центру</div>
</div>
```

### Колонка с прижатым низом

```html
<div class="flex flex-col gap-4">
  <header>Шапка</header>
  <main class="flex-1">Контент растягивается</main>
  <footer>Подвал прижат к низу</footer>
</div>
```

### Теги с переносом

```html
<ul class="flex flex-wrap gap-2">
  <li>react</li>
  <li>typescript</li>
  <li>rsbuild</li>
</ul>
```

`gap-2` даёт отступ и между тегами, и между рядами.

### Две колонки, одна фиксированная

```html
<div class="flex gap-6">
  <aside class="basis-64 shrink-0">Сайдбар 256px</aside>
  <main class="flex-1">Контент занимает остальное</main>
</div>
```

## Грабли

**Текст не обрезается.** Флекс-элемент по умолчанию не сжимается меньше своего
содержимого — минимальный размер равен `auto`, то есть по контенту. Без
`min-width: 0` на растягивающемся блоке не сработают ни `text-overflow: ellipsis`,
ни `overflow: hidden`, ни внутренняя прокрутка. Класса `min-w-0` в наборе нет,
добавьте свойство в свой CSS для этого блока.

**`flex-1` — это не `width: 100%`.** Первый делит свободное место между
элементами, второй требует все 100% ширины родителя и легко вызывает
переполнение.

**`items-center` отменяет растягивание.** По умолчанию у контейнера
`align-items: stretch`, и дети занимают всю высоту. Поставили `items-center` —
дети сжались по содержимому, и `height: 100%` у них перестал работать.

**`justify-items` во флексе не действует.** Это свойство грида. Во флексе за
поперечную ось отвечают `items-*` и `self-*`.

**Порядок правил.** Файл плоский, все селекторы одной специфичности, поэтому
при конфликте выигрывает тот класс, который **ниже в файле**, а не тот, что
правее в атрибуте `class`. Например `flex-1` задаёт `flex-shrink: 1`,
а `shrink-0` идёт ниже и перебивает его — `class="flex-1 shrink-0"` работает,
как ожидается. Обратный порядок в атрибуте ничего не изменит.

**Адаптива нет.** Генератор не делает `md:flex-row` — полная матрица
брейкпоинтов раздула бы файл в пять раз. Нужный набор оборачивается вручную:

```css
@media (min-width: 48rem) {
  .md\:flex-row {
    flex-direction: row;
  }
  .md\:gap-8 {
    gap: 32px;
  }
}
```

Брейкпоинты как в Tailwind: `sm` 40rem (640px), `md` 48rem (768px),
`lg` 64rem (1024px), `xl` 80rem (1280px), `2xl` 96rem (1536px).

**Классы не собираются из строк.** ``className={`gap-${n}`}`` работает, потому что CSS
статический и все классы уже в файле — в отличие от Tailwind, который сканирует
исходники и такой класс не найдёт. Но опечатку никто не поймает: несуществующий
`gap-13` просто ничего не сделает.
