# CSS-утилиты

Четыре файла статического CSS, сгенерированные скриптами на чистом Node.
Именование как в Tailwind — но это просто CSS: ни сборщика утилит, ни
рантайма, ни сканирования исходников.

| Файл                | Классов | О чём                                  | Справочник                       |
| ------------------- | ------- | -------------------------------------- | -------------------------------- |
| `utils/flex.css`    | 217     | display, оси, gap, order, basis        | [flex](/guide/styles/flex)       |
| `utils/grid.css`    | 182     | колонки, строки, span, auto-flow       | [grid](/guide/styles/grid)       |
| `utils/margin.css`  | 722     | внешние отступы, включая отрицательные | [margin](/guide/styles/margin)   |
| `utils/padding.css` | 332     | внутренние отступы                     | [padding](/guide/styles/padding) |

Подключены все четыре — через `src/app/styles/index.css`.

## Генерация

```bash
npm run styles:flex
npm run styles:margin
npm run styles:padding
npm run styles:grid
```

Флаги идут после `--`:

```bash
npm run styles:flex -- --prefix con-        # .con-flex, .con-items-center
npm run styles:flex -- --step 2             # gap-4 станет 8px
npm run styles:flex -- --prefix con- --step 2
```

Скрипты лежат в `scripts/css/`, общая часть — в `_shared.mjs`. Зависимостей нет.

:::danger Файлы в utils/ руками не правят
`src/app/styles/utils/*.css` перезаписываются целиком при каждой генерации.
Нужен новый класс — меняйте генератор.
:::

## Про префикс

Сейчас файлы сгенерированы с `--prefix cost-`, поэтому в разметке классы
называются `cost-flex`, `cost-m-4`, а отрицательные — `-cost-mt-4`
(префикс приклеивается **после** минуса, как в Tailwind).

Зачем он вообще: в режиме микрофронтенда (`npm run dev:mf`) стили хоста и
remote'а оказываются на одной странице. Голый `.flex` там почти наверняка
с чем-нибудь столкнётся — выиграет тот CSS, что загрузился последним.

Текущий префикс всегда видно в шапке самого файла, строка «Сгенерировано».

## Шаг шкалы

Числовые классы считаются в пикселях: **число в классе × шаг**, по умолчанию
4px. `gap-4` = 16px, `m-2.5` = 10px, `*-px` = 1px, `*-0` = 0.

:::warning Шаг держите общим
`--step` у flex и margin задаётся независимо. Если сделать их разными,
`gap-4` и `m-4` перестанут означать одно и то же. Меняете шаг — прогоняйте
все четыре генератора с одинаковым значением.
:::

## Где живая песочница

На странице [flex](/guide/styles/flex) — она написана в `.mdx` и подключает
