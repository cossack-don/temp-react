:::tip Как переименовать
Имя файла задаёт адрес: `guide/docs/section-1.md` → `/guide/docs/section-1`.
Подпись в сайдбаре — отдельно, в `docs/guide/docs/_meta.json`.
Переименовали файл — поправьте `name` там же и ссылки выше, иначе
`npm run docs:build` упадёт на проверке мёртвых ссылок.
:::
