# margin-утилиты

Набор из 720 CSS-классов для внешних отступов. Именование как в Tailwind,
но это обычный статический CSS: ни сборщика утилит, ни рантайма, ни сканирования
исходников. Файл `src/app/styles/utils/margin.css` целиком генерируется скриптом.

> **Про префикс в примерах.** Ниже классы записаны без префикса — `flex`, `m-4`.
> Сейчас файлы сгенерированы с `--prefix cost-`, поэтому в разметке они
> называются `cost-flex`, `cost-m-4`, а отрицательные — `-cost-mt-4`.
> Проверить текущий префикс можно в шапке самого CSS-файла, строка
> «Сгенерировано».

---

## Генерация

```bash
npm run styles:margin                            # .m-4 = 16px
npm run styles:margin -- --prefix con-           # .con-m-4, отрицательные → -con-mt-4
npm run styles:margin -- --step 2                # .m-4 = 8px
npm run styles:margin -- --prefix con- --step 2
```

Скрипт: `scripts/css/generate-margin.mjs`, общая часть — в `scripts/css/_shared.mjs`.
Чистый Node, без зависимостей. Результат: `src/app/styles/utils/margin.css`
(перезаписывается целиком).

> **Файл руками не правят.** Любая правка исчезнет при следующей генерации.
> Нужен новый класс или другое значение — меняйте генератор.

### Префикс

Приклеивается к имени класса, у отрицательных — **после** минуса:

| без префикса | `--prefix con-` |
|---|---|
| `.m-4` | `.con-m-4` |
| `.mx-auto` | `.con-mx-auto` |
| `.-mt-8` | `.-con-mt-8` |
| `.space-y-6 > * + *` | `.con-space-y-6 > * + *` |

Зачем: в режиме микрофронтенда (`npm run dev:mf`) стили хоста и remote'а
оказываются на одной странице, и голый `.m-4` там почти наверняка
с чем-нибудь столкнётся — выиграет тот CSS, что загрузился последним.

### Шаг шкалы

Значение считается как **число в классе × шаг**. Шаг задаётся флагом `--step`,
по умолчанию 4px:

| класс | `--step 4` | `--step 2` | | класс | `--step 4` | `--step 2` |
|---|---|---|---|---|---|---|
| `-0` | 0 | 0 | | `-9` | 36 | 18 |
| `-px` | 1 | 1 | | `-10` | 40 | 20 |
| `-0.5` | 2 | 1 | | `-11` | 44 | 22 |
| `-1` | 4 | 2 | | `-12` | 48 | 24 |
| `-1.5` | 6 | 3 | | `-14` | 56 | 28 |
| `-2` | 8 | 4 | | `-16` | 64 | 32 |
| `-2.5` | 10 | 5 | | `-20` | 80 | 40 |
| `-3` | 12 | 6 | | `-24` | 96 | 48 |
| `-3.5` | 14 | 7 | | `-28` | 112 | 56 |
| `-4` | 16 | 8 | | `-32` | 128 | 64 |
| `-5` | 20 | 10 | | `-40` | 160 | 80 |
| `-6` | 24 | 12 | | `-48` | 192 | 96 |
| `-7` | 28 | 14 | | `-56` / `-64` | 224 / 256 | 112 / 128 |
| `-8` | 32 | 16 | | `-80` / `-96` | 320 / 384 | 160 / 192 |

`-px` — ровно 1 пиксель независимо от шага, для подгонки границ.
`-0` — ноль без единиц.

Шаг у flex и margin задаётся независимо, но держать их разными — плохая идея:
`gap-4` и `m-4` перестанут означать одно и то же. Меняете шаг — прогоняйте оба
генератора с одинаковым `--step`.

## Справочник классов

### Стороны

| префикс | CSS-свойство | что задаёт |
|---|---|---|
| `m-*` | `margin` | все четыре стороны |
| `mx-*` | `margin-inline` | слева и справа |
| `my-*` | `margin-block` | сверху и снизу |
| `mt-*` | `margin-top` | сверху |
| `mr-*` | `margin-right` | справа |
| `mb-*` | `margin-bottom` | снизу |
| `ml-*` | `margin-left` | слева |
| `ms-*` | `margin-inline-start` | начало строки: слева в LTR, справа в RTL |
| `me-*` | `margin-inline-end` | конец строки |
| `mbs-*` | `margin-block-start` | начало блока, зависит от `writing-mode` |
| `mbe-*` | `margin-block-end` | конец блока |

Каждый префикс идёт по всей шкале: `m-0`, `m-px`, `m-0.5`, `m-1` … `m-96`.

### auto

`m-auto`, `mx-auto`, `my-auto`, `mt-auto`, `mr-auto`, `mb-auto`, `ml-auto`,
`ms-auto`, `me-auto`, `mbs-auto`, `mbe-auto`.

`auto` съедает всё свободное место с этой стороны. Отсюда два приёма:
`mx-auto` центрирует блок по горизонтали, `ml-auto` прижимает элемент вправо.

### Отрицательные

Минус перед классом, по всей шкале кроме нуля: `-m-4`, `-mx-2`, `-mt-px`,
`-ms-6` и так далее. Вытягивают элемент за границы родителя.

### space-*

| класс | что делает |
|---|---|
| `space-x-<шкала>` | `margin-inline-start` всем детям, кроме первого |
| `space-y-<шкала>` | `margin-block-start` всем детям, кроме первого |

Селектор — `.space-y-6 > * + *`, то есть отступ получают только соседи после
первого элемента.

## Типовые приёмы

### Центрированный контейнер

```html
<div class="mx-auto" style="max-width: 48rem">…</div>
```

`mx-auto` работает только если у блока задана ширина — `max-width`, `width`
или аналог. Без неё блочный элемент и так занимает всю строку, делить нечего.

### Прижать элемент к правому краю

```html
<header class="flex items-center gap-4">
  <span>Логотип</span>
  <nav class="ml-auto flex gap-3">
    <a href="/about">О нас</a>
    <a href="/contacts">Контакты</a>
  </nav>
</header>
```

`ml-auto` съедает всё свободное место слева. Надёжнее `justify-between`,
когда элементов в шапке больше двух.

### Вертикальный ритм

```html
<article>
  <h2>Заголовок</h2>
  <p class="mt-2">Первый абзац.</p>
  <p class="mt-4">Второй абзац.</p>
</article>
```

Правило: по всему проекту задавайте отступ **либо только сверху** (`mt-*`),
**либо только снизу** (`mb-*`). Смешение двух подходов и есть главный источник
непредсказуемых схлопываний.

### Картинка на всю ширину карточки

```html
<div style="padding: 24px">
  <img class="-mx-6 -mt-6 mb-4" src="…" />
  <h3>Заголовок</h3>
</div>
```

Отрицательный отступ вытягивает картинку за внутренний padding карточки,
и она ложится вплотную к её краям. Значение `-mx-6` должно совпадать с padding
родителя — здесь 24px. Генератора padding-утилит в проекте нет, поэтому padding
в примере задан инлайном.

### Разделитель во всю ширину секции

```html
<section style="padding: 24px">
  <hr class="-mx-6 my-8" />
</section>
```

### Кнопки без двойной границы

```html
<div class="flex">
  <button>Один</button>
  <button class="-ml-px">Два</button>
  <button class="-ml-px">Три</button>
</div>
```

Соседние рамки по 1px накладываются друг на друга вместо того, чтобы дать 2px.

### Отступы между детьми без flex

```html
<ul class="space-y-3">
  <li>Первый</li>
  <li>Второй</li>
  <li>Третий</li>
</ul>
```

## Грабли

**Схлопывание вертикальных отступов.** `mb-4` у одного блока и `mt-8` у
следующего дадут не 48px, а 32px — берётся больший из двух, а не сумма.
Схлопывание **не работает** внутри `flex` и `grid`, при `overflow` отличном от
`visible` и когда между блоками стоит padding или border родителя. Поэтому в
разметке на флексе о нём обычно не думают, а в обычном потоке — регулярно
натыкаются.

**Порядок правил важнее порядка в атрибуте.** Все классы одной специфичности,
поэтому при конфликте выигрывает тот, что **ниже в файле**. Порядок сторон в
`margin.css`: `m`, `mx`, `my`, `mt`, `mr`, `mb`, `ml`, `ms`, `me`, `mbs`, `mbe`.
Значит `class="mx-auto ms-4"` даст `margin-inline-start: 16px`, а `auto`
останется только справа — независимо от того, как вы переставите классы в
атрибуте. Это сочетание встречается чаще всего, о нём стоит помнить.

**`mx-auto` не центрирует flex-элемент так, как ожидается.** Внутри
флекс-контейнера он сработает, но обычно нужнее `justify-center` на родителе.

**Отрицательный margin ломает клики.** Элемент уезжает под соседа, и по
перекрытой области попадает не туда, куда вы думаете. Проверяйте порядок в DOM
и `z-index`.

**Не смешивайте `space-*` и `gap-*`** на одном контейнере — отступы сложатся.
Выберите что-то одно, и в flex/grid это почти всегда `gap-*`: он корректно
работает при переносе строк, а `space-*` в этом случае раздаёт отступ всем,
кроме первого элемента, и ряды слипаются.

**`space-*` конфликтует с собственными margin детей.** Классы вешают
`margin-inline-start` / `margin-block-start` на `> * + *`, и если у ребёнка уже
есть свой `mt-*`, выиграет тот, что ниже в файле.

**Адаптива нет.** Генератор не делает `md:mt-8` — полная матрица брейкпоинтов
раздула бы файл в пять раз. Нужный набор оборачивается вручную:

```css
@media (min-width: 48rem) {
  .md\:mt-8 { margin-top: 32px; }
  .md\:mx-auto { margin-inline: auto; }
}
```

Брейкпоинты как в Tailwind: `sm` 40rem (640px), `md` 48rem (768px),
`lg` 64rem (1024px), `xl` 80rem (1280px), `2xl` 96rem (1536px).

**Опечатку никто не поймает.** Несуществующий `mt-13` просто ничего не сделает —
это статический CSS, а не Tailwind со сканированием исходников.
