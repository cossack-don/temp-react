# Краткое погружение в Шаблон React.js

## Инфраструктура

```md
- src (Исходники клиента на React.js)
- server (API моковый на express.js)
- docs (Документация по проекту на rspress.rs)
- testing (Тесты для проекта на Playwright)
```

### Client

```bash
# Запуск solo Frontend

npm install
npm run dev # http://localhost:3000

npm run build # прод-сборка в dist/
npm run preview # локальный просмотр прод-сборки
```
